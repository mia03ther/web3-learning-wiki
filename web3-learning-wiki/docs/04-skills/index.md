## 学习原则

- **免费资源完全足够学到「能找实习」的水平**，关键是坚持 + 做项目，不必买昂贵的课；
- 一次只跟一条主线，**学完立刻产出**（笔记 / 小项目），不要收藏一堆却从不开始；
- 所有资源请自己再核实一遍时效性，技术领域更新很快。
