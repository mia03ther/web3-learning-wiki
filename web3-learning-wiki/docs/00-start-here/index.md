# 从这里开始

## 我是谁

- 广东外语外贸大学本科生，2026 年入学（大一）；
- 入学时接近「技术小白」：没有系统学过编程，对区块链只有模糊印象；
- 目标：四年后申请香港 / 新加坡的 Web3 / 金融科技方向硕士，毕业后进入 Web3 行业；
- 优势：语言能力、英语、跨文化沟通、愿意持续输出。

## 我为什么建这个 Wiki

参加了两场行业活动后，我最大的感受是：**行业里的人讲的东西，小白有一半听不懂**，但网上又很难找到「既讲人话、又跟得上 2026 年行业现状」的中文资料。

所以我决定自己动手：每学懂一点，就用小白能看懂的话写下来。这个过程同时完成三件事：

1. **逼自己学懂**（能给别人讲明白，才是真懂）；
2. **沉淀作品集**（申研、找实习时，这个仓库就是证据）；
3. **打造个人 IP**（在 Web3 行业，公开贡献比简历有说服力）。

## 五条学习心法（贯穿整个 Wiki）

### 1. 输出 > 输入

看 10 小时视频，不如写 1 小时笔记、做 1 个小项目。**每一次学习都要留下公开的痕迹**（一篇笔记、一个 commit、一条总结）。

### 2. 项目驱动，而不是课程驱动

不要想着「等我把所有基础学完再做项目」——那一天永远不会来。正确路径是：**学一点基础 → 立刻做一个小东西 → 遇到不懂的再回去补**。黑客松是最好的学习加速器。

### 3. 先守住「能控制的事」

AI 怎么发展、行业牛熊、招生政策，这些我控制不了，少想；我能控制的是：今天的 GPA、英语、代码练习、一篇笔记。把注意力放在自己能控制的事情上，焦虑会少一大半。

### 4. 发挥自己的差异化优势

我不是计算机强校出身，硬拼算法没有优势。我的差异化是 **「语言 + 技术」的桥梁定位**：

- 快速读懂英文一手资料，翻译成中文笔记；
- 做华语项目「出海」和海外项目「入华」的信息差桥梁；
- 行业里反复出现的关键词是「出海」「东西方串联」——这正是语言类学生的机会。

### 5. 不碰看不懂的钱

Web3 行业充满投机故事。原则：**不炒币、不加杠杆、不参与看不懂收益从哪来的项目**。我要做的是「建铁路的人」，不是「赌桌上的人」。先用测试网、小额、模拟盘学习。

## 关于笔记的可信度说明

会议精读音译自现场录音转写稿，部分专有名词可能有误差（例如人名、项目名）。我会：

- 对能核实的名词给出标准写法（如「Monet / Mona」应为 **Monad**）；
- 对不确定的内容明确标注「*待核实*」；
- 所有外部事实尽量附来源链接；申请要求等信息请务必以官网最新公布为准。
