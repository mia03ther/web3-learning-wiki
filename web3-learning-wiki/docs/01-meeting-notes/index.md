# 会议精读

这里是我参加行业活动后的「嚼碎版」笔记。每篇都按统一结构写：

> **这场活动讲了什么 → 每个项目逐一拆解（解决什么痛点 / 怎么解决 / 小白能学到什么）→ 延伸概念 → 我能立刻做的事**

## 笔记列表

1. [**路演夜：四个 AI × Web3 项目**](./01-pitch-night.md)
   AI 钱包（Monet Switch）、浏览器里的果蝇数字员工、多 Agent 预算控制（Text Permit）、完全去中心化扑克协议。
2. [**Monad 黑客松宣讲与 Agent 金融圆桌**](./02-monad-hackathon.md)
   Monad 公链技术架构、25 万美元全球黑客松参赛指南、SignalPlus 的 AI 交易系统、VC 圆桌谈 Agent 如何改变金融、三个 Demo 项目。

## 阅读提示

- 文中 `【概念】` 标记的词，都能在 [小白词典](../02-glossary/01-beginner-dictionary.md) 里找到解释；
- 会议由录音转写，口语化且有同音误差，我会在文中随时纠正（例如「Monet / Mona / Monai」= **Monad**，一条高性能公链）；
- 每篇结尾都有「**我现在能做什么**」，把听来的东西变成自己的行动。
