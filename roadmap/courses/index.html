    精选课程中心

    A curated, link-first catalog of free courses — from programming basics to Solidity, security, DeFi and AI × Web3. 点击卡片右下角「去上课」直达官网。

    怎么用

    1. 零基础：先学模块 1（编程地基），再走模块 2-3；
    2. 有编程基础：直接从模块 2 / 3 进入 Web3；
    3. 每学完一门，回到 学习路线图 打勾，并在知识库写一篇笔记。

    1 · 编程与 CS 基础（地基）

    Harvard入门
    CS50x
    最经典的计算机科学导论，讲计算思维、C、Python、SQL 与 Web，风趣、零基础友好。
    去上课 →
    freeCodeCamp入门
    freeCodeCamp
    全免费、项目驱动，覆盖响应式网页、JS、数据、后端，有中文界面与大量视频。
    去上课 →
    Odin Project中级
    The Odin Project
    一条完整的 Web 全栈路线（HTML/CSS/JS → Node → React），边做项目边学。
    去上课 →
    MDN工具书
    MDN Web Docs
    最权威的 HTML / CSS / JavaScript 参考手册，遇到前端问题先查它。
    去上课 →

    2 · Web3 / 区块链入门

    Alchemy入门
    Introduction to Blockchain
    从 Web1/2/3 历史讲到代币、智能合约、DeFi、NFT、DAO，10 章 43 课，完全免费。
    去上课 →
    ethereum.org入门
    以太坊学习工具合集
    官方整理的学习路径、教程与开发者工具，按入门到进阶分类，是最可靠的起点。
    去上课 →
    WTF Academy中文
    WTF Academy
    中文 Web3 开源学院，含 Solidity、Ethers.js、合约安全等系列，对中文学习者友好。
    去上课 →

    3 · Solidity 与智能合约

    CryptoZombies入门
    CryptoZombies
    通过做一个僵尸游戏学 Solidity，浏览器内完成、零配置，第一课就写真实合约。
    去上课 →
    Cyfrin Updraft进阶
    Cyfrin Updraft
    Patrick Collins 主讲，Foundry / Solidity / 安全 / DeFi 最权威免费体系，行业标准。
    去上课 →
    Alchemy中级
    Learn Solidity
    用 Solidity 0.8.x 学现代语法与最佳实践，浏览器内编码，配套 Foundry 测试。
    去上课 →
    solidity-by-example工具书
    Solidity by Example
    每个语法点配一个可运行的简短例子，写合约时当速查手册非常顺手。
    去上课 →
    Remix工具
    Remix IDE
    浏览器里的官方智能合约 IDE，编译、部署、调试一条龙，入门无需本地环境。
    去上课 →

    OpenZeppelin中级

    Capture the Ether中级
    Capture the Ether
    另一套以太坊 CTF，覆盖合约安全基础，适合 Ethernaut 之后继续刷。

    Gas 优化教程
    系统讲 Solidity Gas 优化技巧（Decert 中文翻译），进阶必备。
    去上课 →
