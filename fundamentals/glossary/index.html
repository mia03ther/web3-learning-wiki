    会议黑话对照表¶

    两份会议由现场录音自动转写，大量专有名词被写成了谐音 / 错别字。这张表把它们对应回标准写法，方便你对照原文阅读。

    标记说明：✅ 已核实（有公开资料佐证）｜❓ 待核实（我的推测，请以官方为准）。

    一、链 / 平台 / 活动¶

    转写里出现的词 标准写法 说明

    my troubles、雷克雷克索、门车会、买车宝 Monad 黑客松（官网） ❓ 具体平台域名以 Monad 官方公布为准

    salon 的 collison Collision（科技大会） ❓ 被对标的全球性大会

    三类、三笠 Sui（公链） ❓ 结合「开源、政府方向」语境推测

    给我的提醒（信息素养）¶

    1. 自动转写不能全信：读行业资料遇到「明显不通」的词，要主动怀疑是谐音，去搜原始术语；
    2. 区分「已核实」和「推测」：笔记里要把这两者分开标注，这是严谨的学习习惯；
    3. 所有项目名、申请要求、数据，以官方渠道（官网、官方 X / 文档）为最终依据；
    4. 以后我自己整理会议笔记，也应该顺手产出这样一张对照表——这对读者价值很大。
