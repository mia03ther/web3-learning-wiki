    Web3 运营入门（笔记）

    一条主线：先理解目标，再动手。

    1. 连续问「为什么」：接到「发优惠券 / 做活动」这类动作型任务，先追到根因 （是价格、信任、产品体验，还是渠道用户不匹配？）——先诊断，再开药；
    2. 记住四要素：目标（想改变什么）· 用户（影响谁）· 动作（做什么）· 数据（如何判断结果）；
    3. 三大方向：
    4. 活动运营：AMA / 课程 / Workshop / Demo Day，分「开始前 · 进行时 · 结束后」 一条完整链条（目标 → 筹备 → 执行 → 收尾 → 跟进）；
    5. 社媒运营：X / LinkedIn / 小红书等，安排发布节奏、避免重复；区分 KOL（有影响力的创作者）、KOC（贴近日常体验的消费者型创作者）、 KOS（偏销售转化，进团队先确认定义）；
    6. 社群运营：Discord / Telegram / 微信群，做好新人引导与真实参与—— 消息多 ≠ 效果好，要看有多少真实成员完成目标动作；
    7. 数据复盘：任何比例都要说明分母；一页周报保留「目标 / 动作 / 数据 / 问题 / 下一步」五类信息。

    初入职场（笔记）

    • 认知重启：学校像「跟团游」——有人带路、有标准答案、做对有分数；职场像 「自由行」——路线自己找、信息自己挖，没人理是常态，不是你不受欢迎；
    • 同事关系：别只埋头干活，跨部门信息往往在午饭、茶水间的闲聊里；学会 small talk，让自己不做「信息孤岛」；
    • 领导关系：老板不是老师，是「要结果的人」。降低带教成本靠三项递增能力： 洞察（抓住关键信息）→ 总结（消化成自己的）→ 表达（给信息增量）；
    • 预期管理：先攒「特异学分」——先遵守规范、配合团队、成为自己人， 才有资格做不一样的事；新人不宜一上来就打破惯例；
    • 工作汇报：「干得好」也要「说得好」，汇报先说结论与结果，再讲问题与方案。

    监管与合规（风险意识）

    参考：刘红林律师《中国 Web3 监管解读 · 法律风险防范》（上海曼昆律师事务所，25 页）。

    不同地区对虚拟货币的监管差异很大。在中国大陆，虚拟货币相关业务活动受到严格监管， 参与前应了解常见风险类别：

    • 发币 / 募资：代币发行、公开募资极易触碰非法金融活动红线；
    • 交易与出入金：虚拟货币交易、法币与币的兑换存在合规与资金安全风险；
    • 为境外项目工作：即使雇主在境外，仍需关注境内法律、结算与税务问题；
    • 个人信息与资金安全：诈骗、钓鱼、黑钱流入是高频风险。

    免责声明

    以上仅为风险意识提示，不构成法律或投资意见，也不提供任何规避监管的方法。 重大决策请咨询专业律师，并以所在地最新法律法规为准。
