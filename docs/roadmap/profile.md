# 标化与背景建设

> 语言能力是重要的「王牌科目」，目标是把优势转化为录取竞争力；背景建设则是
> 长期积累、建立整体可信度的主战场。

## 一、雅思 / 托福

### 目标分数

| 目标档位 | 建议分数 |
|---|---|
| 主申 / 稳妥 | 雅思 **6.5**（小分 6.0）通常基本够用 |
| 冲刺更具竞争力的项目 | 雅思 **7.0+**（小分 6.0-6.5）更稳 |
| 顶尖 / 奖学金 | 雅思 7.5+ 更有竞争力 |

> 托福对应参考：雅思 6.5 ≈ 托福 90 左右；雅思 7.0 ≈ 托福 100 左右。多数项目两者
> 都接受，可按自身训练体系选择更顺手的一种。

### 时间规划（关键：成绩有效期约 2 年）

- **早期阶段**：打基础 + 模考 / 一战摸底，先暴露问题，不急于出分；
- **中期阶段**：**正式出分**，并留出重考空间；
- 若成绩在申请 / 入学时将过期，安排重考，确保全程有效。

### 备考策略（结合专业学习）

- **听力 / 阅读**：直接用英文 Web3 / AI 资料当素材，备考与专业学习一举两得；
- **写作**：把知识库笔记的英文摘要、公开平台发帖当练习；
- **口语**：用英语复述项目、参加线上英语角 / 国际社群语音；
- 充分利用身边的外教、语言课与英语角等资源。

## 二、GRE / GMAT

### 要不要考

- 部分偏量化 / 计算机的金融科技项目**明确建议或要求**（常见参考：GRE 320+ / GMAT 700+）；
- 其他项目多数不强制，但**高分可以加分、增强整体材料的说服力**。

### 选哪个

- **GRE**：适用面更广，理工、金融科技、数据 / 计算机方向都认可，**优先选 GRE**；
- **GMAT**：纯商学院 / 金融方向更对口；
- 时间上集中攻克，避免与申请季撞车。

> 标化是「门票」不是「亮点」，达到目标线即可，不必无限刷分；时间更应留给 GPA、
> 项目与实习。

## 三、背景建设

### 1. 交换 / 暑校 / 联合培养

- 优先争取目标地区的学期交换 / 暑期学校（提前接触目标院校、拿推荐信、体验当地）；
- 关注学校国际处的合作项目与资助名额；
- 线上国际课程 / 证书可作为补充，但**有成绩单和推荐信的线下项目通常含金量更高**。

### 2. 科研（冲研究型 / 名校时尤其重要）

- 尽早主动联系教授做 **RA（研究助理）**，方向贴合区块链 / AI 金融 / 数据；
- 争取产出：会议 / 工作坊论文、技术报告、公开数据集；
- 即使申请授课型项目，**科研经历也能显著提升故事可信度**，并带来学术推荐信。

### 3. 竞赛

| 类型 | 例子 | 价值 |
|---|---|---|
| **黑客松**（最重要） | 公联赛、ETH Global、Dorahacks | 直接对口，有奖金 + 作品 + 人脉 |
| 数据 / AI | Kaggle、天池等数据竞赛 | 证明工程与数据能力 |
| 数学建模 | 国赛 / 美赛（MCM/ICM） | 量化能力背书 |
| 商赛 | 金融 / 咨询 / 创业大赛 | 适合复合 / 非技术路线 |

### 4. 实习（权重最高的软背景之一）

- 目标：**2-3 段 Web3 / 金融科技相关实习**，优先知名项目、目标地区实地、有推荐信；
- 早期可从远程 / 运营 / 内容 / 社区切入，逐步过渡到技术 / 投研；
- 详见 [实习与求职指南](../handbook/internship.md)。

### 5. 作品集 / 公开内容

- 这个 **知识库 + 项目仓库 + 个人网站**就是核心作品集；
- 公开的技术博客、开源贡献与平台内容，构成可验证的「能力证据链」；
- 详见 [GitHub 与本站搭建](../handbook/github-site.md)。

### 6. 推荐信策略

- 理想组合：**1 位专业课 / 科研教授 + 1 位实习 / 项目负责人 + 1 位交换 / 业界导师**；
- 推荐信要「具体」：推荐人能讲出你做过的项目、表现出的能力；
- 尽早让老师记住你（上课、提问、做项目、协助工作），**临时抱佛脚要不到强推**。

## 四、背景建设阶段总表

| 阶段 | 语言 / 标化 | 科研 / 交换 | 竞赛 / 实践 |
|---|---|---|---|
| Phase 1 | 语言基础 + 一战摸底 | 认识老师、进实验室旁听 | 逛黑客松、建知识库 |
| Phase 2 | **语言出分** | RA / 暑校 | **第一次黑客松**、1 段实习 |
| Phase 3 | **GRE/GMAT**、必要时重考语言 | 论文 / 研究产出 | 黑客松获奖、**多段强实习** |
| Phase 4 | 补齐有效期 | 毕设结合 Web3 | 申请、面试、拿 Offer |

## 五、文书故事线（长期经营）

招生方希望看到一个**连贯、可信、有证据**的故事，例如：

> 「我在学习早期接触到 AI Agent 与链上支付这一真实趋势（附精读笔记）→ 被『让 AI
> 安全地参与经济』吸引而系统学习智能合约（附课程与项目）→ 通过黑客松和实习不断
> 验证兴趣与能力（附作品、获奖、推荐信）→ 现在希望在贵校（具体到课程 / 教授 /
> 生态）深入，未来投身全球数字资产行业。」

**这个故事不是申请时「写」出来的，是长期「做」出来的。** 每篇笔记、每个项目，
都在为文书积累素材。
