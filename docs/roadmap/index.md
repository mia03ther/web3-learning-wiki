# Roadmap

把「长期学习 → 动手实践 → 在全球 Web3 生态深造与从业」拆成可执行、可迭代的计划。

## 在这一板块

- [**学习路线图**](./learning-path.md)：分阶段的基础、技术、实践与输出目标，
  以及关键里程碑；
- [**技能树与资源**](./skills-resources.md)：技术 / 金融 / 复合三棵技能树、
  免费课程、信息源与工具；
- [**标化与背景建设**](./profile.md)：语言与标化、科研、竞赛、实习、推荐信
  与作品集；
- [**海外深造参考**](./graduate-study.md)：相关方向研究生项目的客观对比与申请
  准备要点。

## 三个优先级

1. **基础与成绩是长期硬通货**，从当下每一次练习与每一门课积累，没有「以后再补」；
2. **可迁移能力尽早建立**：英语、编程、信息检索与公开表达，越早形成习惯，后面越从容；
3. **软背景靠持续积累**：项目、黑客松、开源、实习、科研与推荐关系，按节奏推进，不必焦虑。
