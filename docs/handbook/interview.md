# 面经题库

> 区块链 / Web3 方向的面试题库与本地资料索引。技术岗（合约 / 前端 / Go 后端）
> 与综合认知都覆盖，建议配合 [实习与求职指南](./internship.md) 使用。

## 怎么刷

1. **先建框架**：通读 [核心概念词典](../fundamentals/core-concepts.md)，能讲清每个术语；
2. **按目标岗位刷**：合约岗刷 Solidity/EVM，前端岗刷 dapp 前端，后端刷 Go；
3. **动手验证**：每道题自己写一遍答案 / 跑一段代码，不要只看不练；
4. **沉淀到知识库**：把高频题整理成自己的问答笔记。

## 简历要点

- **一页、英文**，结构：教育 / 技能 / 项目（黑客松）/ 实习 / 开源链接；
- 每条经历用「**做了什么 + 结果 / 数据**」描述，例如「用 Foundry 写测试，覆盖 X 个分支」；
- 每个 GitHub 项目都要有 README、能运行、最好有 Demo；
- 统一「个人名片」：GitHub、个人网站、X、LinkedIn 互相链接。
