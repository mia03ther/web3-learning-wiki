# Web3 实习求职指南

> 怎么把长期积累变成第一份实习 / 工作。包含岗位地图、目标公司、投递渠道、简历作品集和面试准备，技术与非技术路线都覆盖。

## 一、Web3 岗位地图（先选赛道）

### 技术岗

| 岗位 | 做什么 | 要求 |
|---|---|---|
| 智能合约工程师 | 写 / 维护 Solidity 等合约 | Solidity、Foundry、安全 |
| 全栈 / 前端 dApp | 做产品界面与交互 | JS/TS、React、ethers/viem |
| 后端 / 基础设施 | 节点、索引、API、撮合 | Go/Rust/Node、分布式系统 |
| ZK / 密码学工程师 | 证明系统、隐私扩容 | 密码学、数学（门槛高） |
| 安全 / 审计 | 找合约漏洞 | 合约 + 漏洞库 + 实战 |
| 数据工程师 / 量化 | 链上数据、策略 | SQL、Python、统计 |

### 非技术岗（语言 / 复合背景机会多）

| 岗位 | 做什么 |
|---|---|
| 社区运营 | Discord / 社群、活动、用户关系 |
| 内容 / 新媒体 | 文章、教程、视频、翻译 |
| 市场 / 增长（Marketing/Growth） | 推广、活动、用户增长、出海 |
| 产品经理（PM） | 需求、流程、协调研发 |
| 投研 / 分析师（Research） | 项目 / 行业 / 数据分析 |
| 合规 / 法务（Compliance） | 牌照、监管、KYC（港新很缺） |
| BD / 商务、DevRel、设计 | 合作拓展、开发者关系、UX |

> 会议里几乎每个技术团队都在喊「缺运营」——**社区 / 内容 / 市场 / DevRel 是小白最现实的切入口**，且与语言背景高度契合。

## 二、目标公司与生态（港新 + 远程）

### 香港 🇭🇰（SFC 持牌 + Web3 总部聚集）

- **持牌交易所 / 金融**：HashKey（哈希键，含交易所、资管、代币化，常年招实习）、OSL；
- **Web3 集团 / 生态**：Animoca Brands（Moca Network、The Sandbox 等）、OKX、Amber Group；
- **托管 / 基础设施**：Hex Trust 等；
- 各类基金（VC）、家族办公室、做市 / 量化机构。

### 新加坡 🇸🇬（合规与金融中心）

- **Coinbase、Crypto.com、OKX（亚洲总部）** 等区域总部；
- 各类交易所、机构、银行数字资产部门、Web3 基础设施公司。

### 通用类型（含远程）

- 公链 / L2 基金会与开发公司；DeFi / 交易协议（如 Hyperliquid 类）；
- 钱包、预言机、安全公司、数据平台；加密媒体、VC、孵化器。

> 行业变化快，公司名单要持续更新；**优先选合规、有真实产品、有导师可学的平台**，避开只讲概念 / 拉盘的团队。

## 三、分阶段实习节奏

| 阶段 | 实习目标 |
|---|---|
| Phase 1 | 不苛求，先做线上志愿者 / 社区贡献 / 内容，参加活动积累人脉 |
| Phase 2 | **第一段实习**：远程 / 运营 / 内容 / DevRel 助理 / 初级技术实习 |
| Phase 3 | **多段高质量实习**：目标地区实地或知名项目，争取推荐信 / 留用 |
| Phase 4 | 申请与实习并行；深造期间继续，目标毕业拿全职 Offer |

## 四、简历与作品集（你的「证据链」）

- **简历**：一页，英文；突出教育 / GPA、技能、**项目（黑客松）、实习、开源链接**；用「做了什么 + 结果」描述，附 GitHub / 网站；
- **作品集**：GitHub 主页 + 本 Wiki 网站 + 1-2 个可演示项目，就是最好的简历；
- **项目要能点开看**：每个仓库有 README、能运行、有 Demo；
- 建立统一的「个人名片」：GitHub、X、LinkedIn、邮箱、网站互相链接。

## 六、面试准备

### 通用

- **英文表达**：能用英语讲清自己的项目和动机（语言 + 雅思优势）；
- **讲透作品**：准备 2-3 个「STAR」故事（情境 - 任务 - 行动 - 结果）；
- 了解公司：产品、赛道、近期动态，准备好「为什么是我们 / 这个方向」。

### 技术岗

- 扎实的合约 / 全栈基础 + 手写 / 解释代码；
- 常见漏洞、Gas 优化、测试；能现场讲自己仓库的设计；
- 数据 / 量化：SQL、统计、回测相关。

### 非技术岗

- 运营 / 增长：案例、数据 sense、活动经历；
- 投研：行业框架、分析样稿（可直接用 Wiki 文章）；
- 合规：监管常识（香港 SFC、新加坡 MAS）、细致严谨。

## 七、留港 / 留新工作（简单了解）

- **香港**：有面向毕业生的留港安排（如 IANG，毕业后可留港求职、之后可续），政策对人才较友好；
- **新加坡**：工作需雇主申请就业准证（EP），有薪资 / 资质门槛，名校硕士 + 本地实习更有利；
- 具体政策逐年调整，**以官方入境 / 劳工部门最新规定为准**。

## 八、防坑与心态

1. **警惕「交钱内推 / 包offer / 高薪兼职」骗局**，正规求职不需要你先付钱；
2. 不参与只靠拉新、拉盘、来路不明的「项目方」；
3. 海投 + 精准投结合，被拒很正常，**持续迭代简历和作品**；
4. 先入行、再择业：第一份平台重在学东西、攒履历；
5. 记住前辈的话：**金融 / Web3 建立在信任与人脉上，「难进但难出」，长期信誉最重要**。
