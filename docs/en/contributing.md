# Contribution Guide

This wiki is open source, and the edit entry is the **Edit on GitHub** button in the top-right corner of every page. Typos, corrections, new sources and new notes are all welcome.

## Ways to contribute

- **Open an issue** for corrections, outdated information or broken links at [GitHub Issues](https://github.com/mia03ther/web3-learning-wiki/issues);
- **Edit directly** — use the ✏️ **Edit on GitHub** button on any page and send a pull request;
- **Recommend resources** — share great courses, tools or first-hand material in [Discussions](https://github.com/mia03ther/web3-learning-wiki/discussions);
- **Request edit access** — to become a regular contributor, [apply to join as a collaborator](https://github.com/mia03ther/web3-learning-wiki/issues/new?labels=edit-permission&template=edit-permission.md&title=Edit%20permission%20request).

## Preview locally

Requires Python 3.11+.

```bash
git clone https://github.com/mia03ther/web3-learning-wiki.git
cd web3-learning-wiki
python -m venv .venv
source .venv/bin/activate       # macOS / Linux
# .venv\Scripts\activate        # Windows
pip install -r requirements.txt
mkdocs serve
```

Open <http://127.0.0.1:8000> to preview.

## Before submitting a PR

Make sure the strict build passes:

```bash
mkdocs build --strict
```

## Branches and deployment

- `main` holds all sources and content — **make every edit here**;
- `gh-pages` is generated by GitHub Actions — **never edit it by hand**;
- Every push to `main` triggers a build and deployment.

## Content guidelines

- Put new pages in the matching section (`fundamentals/`, `ai-web3/`, `handbook/` …);
- Chinese content lives at the `docs/` root; English translations go to the matching path under `docs/en/`;
- Cite external facts where possible; mark uncertain content as "to be verified";
- Keep the same heading levels and Markdown style as existing pages.
