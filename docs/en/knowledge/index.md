# Knowledge

<p class="w3-lead">
Topics that come up across the notebook, collected in one place. Start with the basics or jump to the question you have.
This English index links to existing guides; newer topics, including security and AI-assisted development, are in Chinese.
For the event context, see <a href="../field-notes/">Field Notes</a>.
</p>

## Basics

- [Blockchain Basics](../fundamentals/index.md): wallets, transactions, gas, consensus and L1 / L2. Keep the [Core Concepts](../fundamentals/core-concepts.md) nearby for unfamiliar terms.
- [On-chain Data](../onchain-data/index.md): where data comes from, how to query it and how to read it carefully, with links to analysis tools such as Dune.

## Build

- [Smart Contracts](../smart-contracts/index.md): Solidity, Foundry and a testnet workflow for writing, testing and deploying a first contract.
- [Developer Tools](../devtools/index.md): Git / GitHub, contract frameworks and testnet tools. Use this when setting up an environment or choosing a tool.
- [AI-assisted Development](../devtools/ai-coding.md) (Chinese): LLMs, agents and harnesses; context management; `AGENTS.md` and skills; reviewing code after AI writes it.

## Explore

- [AI × Web3](../ai-web3/index.md): agent payments, on-chain agents, AI trading and data assets, with links to project notes.
- [MCP & AI Agents](../ai-web3/mcp-agents.md): how agents call tools and pay for things, and how budgets and permissions are limited.
- [Security & Privacy](../security/index.md) (Chinese): wallet safety, cryptography, on-chain privacy and agent permissions. Read the wallet section early if you are new to wallets.

## Find a starting point

- **An unfamiliar term?** Look it up in [Core Concepts](../fundamentals/core-concepts.md).
- **How should I keep my assets safe?** Start with [asset security](../security/index.md#assets) (Chinese).
- **AI-generated code keeps going wrong?** Read the context and review sections in [AI-assisted Development](../devtools/ai-coding.md) (Chinese).
- **How does an agent pay, and what keeps it within limits?** Read [MCP & AI Agents](../ai-web3/mcp-agents.md).
- **Ready to write a first contract?** Start with [Smart Contracts](../smart-contracts/index.md), then find a course in the [Course Hub](../roadmap/courses.md) (Chinese).

## Using these notes

Skim once to get your bearings, then return while reading an event note or building something. Try explaining a concept in your own words to see which part needs another look.
