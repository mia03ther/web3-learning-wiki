# Fundamentals

Web3 与 AI × Web3 的基础概念区——把行业术语翻译成「人话」，先建立直觉。

- [**核心概念词典**](./core-concepts.md)：按「区块链基础 → 金融（DeFi）→ AI Agent → 安全与证明 → 行业生态」分类的 40+ 概念，配类比与自测题；
- [**黑话对照表**](./glossary.md)：活动录音转写里的谐音 / 口语词，对应到标准写法并标注核实状态。

## 使用方法

1. 读 Field Notes、看行业文章遇到不懂的词，来这里查；
2. 每学一个概念，尝试**用自己的话给别人讲一遍**（费曼学习法）；
3. 第一遍不追求记住，先建立整体地图，再在实践中反复回来查。
