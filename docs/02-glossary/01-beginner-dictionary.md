# Web3 小白概念词典

> 40+ 个核心概念的「人话解释」。建议第一遍通读建立全局印象，以后当字典查。
> 标注：`基础` `金融` `AI` `安全` `生态`。

---

## 一、区块链基础

### 区块链 `Blockchain` `基础`
一种**很多台电脑共同记账、谁也无法独自篡改**的账本。数据被打包成一个个「区块」，按时间顺序连成「链」。关键特征：没有一个单一管理员，记录对所有人公开可查。

### 区块 / 出块时间 `基础`
- **区块（Block）**：一个装着若干笔交易的「数据包」；
- **出块时间**：多久产生一个新区块。Monad 约 0.3 秒，以太坊约 12 秒。

### 节点 `Node` `基础`
参与运行、维护区块链网络的电脑 / 服务器。节点越多、越分散，网络越去中心化、越难被关停。

### 中心化 vs 去中心化 `基础`
- **中心化**：有一个说了算的中心（银行、淘宝、微信），效率高但你要信任它、它能封你号；
- **去中心化**：没有单一控制方，规则由代码和多数节点执行，抗审查、无需许可，但通常更慢、更难用。

### 共识机制 `Consensus` `基础`
让互不认识的节点「就账本内容达成一致」的规则。两大主流：
- **PoW（工作量证明）**：比特币用，靠算力竞赛记账，耗电；
- **PoS（权益证明）**：以太坊现在用，靠质押代币获得记账权，更节能。

### 以太坊 `Ethereum` `基础`
仅次于比特币的第二大区块链，最大贡献是支持**智能合约**，是 DeFi、NFT 等应用的发源地，生态最大。

### EVM（以太坊虚拟机）`基础`
以太坊上运行智能合约的「操作系统 / 执行引擎」。**「兼容 EVM」= 能直接跑以太坊的程序**，开发者和工具可以平滑迁移。Monad、BNB Chain、Polygon 等都兼容 EVM。

### Layer 1 / Layer 2（L1 / L2）`基础`
- **L1**：底层主链本身（比特币、以太坊、Monad、Solana）；
- **L2**：建在 L1 之上、帮它提速降费的网络（如以太坊的 Arbitrum、Optimism、Base）。

### TPS `基础`
**每秒处理交易数（Transactions Per Second）**，衡量吞吐量。以太坊约十几笔，Monad 宣称约 1 万笔。

### 最终性 `Finality` `基础`
一笔交易被彻底确认、**再也无法回滚**所需的时间。最终性越快，充值、交易体验越好（Monad 约 0.6 秒）。

### Gas（燃料费）`基础`
在链上执行操作要付的**手续费**，用来补偿节点的计算资源。操作越复杂越贵；网络拥堵时涨价。Monad 因性能高、代币便宜，Gas 极低。

### 智能合约 `Smart Contract` `基础`
**部署在区块链上、满足条件就自动执行的程序**，「代码即规则」，部署后通常不可篡改、24 小时运行。例：「你转 100 美元进来，合约自动给你对应代币，不需要任何中介」。

### 钱包 / 地址 / 私钥 / 助记词 `基础`
- **钱包（Wallet）**：管理链上资产的工具（如 MetaMask），它不「装钱」，而是保管钥匙、帮你签名授权；
- **地址（Address）**：你的链上账号，像银行卡号，可以公开（形如 0x123...）；
- **私钥（Private Key）**：账号的「终极密码 / 印章」，**谁拥有谁就能转走资产，绝不能给任何人**；
- **助记词**：把私钥写成 12/24 个单词，方便备份，**同样绝密，且要离线手抄保存**。

### 交易 `Transaction` `基础`
一次链上操作：转账、调用合约、买卖等，都需要钱包签名、支付 Gas、被打包确认。

### 哈希 `Hash` `基础`
把任意数据通过算法变成一串固定长度的「数字指纹」。**数据改一点点，指纹就完全不同**；指纹无法反推出原文。它是区块链防篡改、验证数据的基石。

### 主网 / 测试网 `Mainnet / Testnet` `基础`
- **主网**：真实资产、真实价值运行的正式网络；
- **测试网**：免费的「演练场」，用免费的测试代币开发、试验，**新手应该先在测试网练手**。

### 分叉 `Fork` `基础`
复制一个开源项目 / 链的代码，在其基础上改造（GitHub 上的 Fork）；也指链因共识分歧而分裂。

## 二、Web3 与 DeFi（链上金融）

### Web1 / Web2 / Web3 `金融`
- **Web1**：早期互联网，只能「读」（门户网站、黄页）；
- **Web2**：可读可写，但平台拥有数据和网络（微博、抖音、淘宝）；
- **Web3**：用户通过钱包和代币「拥有」自己的资产与身份，价值归用户，无需许可、可组合。

### DeFi（去中心化金融）`金融`
**Decentralized Finance**，用智能合约搭建的金融系统：交易、借贷、理财、保险、稳定币……不经过银行 / 券商，人人可接入、规则公开。

### CEX / DEX（中心化 / 去中心化交易所）`金融`
- **CEX**：币安、OKX、Coinbase 等，平台帮你托管、撮合，体验好但需信任；
- **DEX**：Uniswap 等，链上自动撮合，资产始终在你自己钱包里。

### 流动性 / 流动性池 / 做市商 `金融`
- **流动性（Liquidity）**：资产能不能快速、低成本地买卖；钱越多越「流动」；
- **流动性池（Liquidity Pool）**：大家把代币存进一个智能合约资金池，供交易撮合；
- **做市商（Market Maker）**：提供买卖报价、提供流动性赚取价差的人 / 机构。

### AMM（自动做市商）`金融`
DEX 用数学公式（如恒定乘积 x×y=k）自动定价、撮合，取代传统订单簿。你往池子里存币，别人就能交易。

### 稳定币 `Stablecoin` `金融`
**价格锚定法币（通常 1 美元）的加密货币**，是 DeFi 的「计价单位和避风港」。
- 主流：**USDT、USDC**（靠储备资产锚定，称法币抵押型）；
- 还有 DAI 等去中心化稳定币。会议中 Agent 支付、跨境电商结算大量用到 USDC。

### 借贷协议 `金融`
智能合约版「银行存贷」：你存款赚利息，别人抵押资产借钱；**抵押率不足会被自动清算**，全程自动。代表：Aave、Compound。

### 质押 `Staking` `金融`
把代币锁定来支持网络安全 / 协议运行，获得奖励收益，类似「存定期拿利息」。

### 收益耕作 `Yield Farming` `金融`
通过在不同 DeFi 协议间提供资金、参与活动来追求收益（可能伴随高风险）。

### 预言机 `Oracle` `金融`
**把链外真实数据（价格、汇率、赛事结果）送进链上的桥梁**。智能合约无法自己上网，DeFi 靠预言机获取价格。代表：Chainlink（中心化程度受质疑）。

### 清算 `Liquidation` `金融`
当借款的抵押品价值跌到阈值以下，协议自动卖掉抵押品还债，保护资金安全。DeFi 爆仓多由此触发。

### 杠杆 / 合约 / 永续合约 `金融`
- **杠杆**：借小钱撬大头寸，放大收益也放大亏损；
- **永续合约（Perpetual / Perp）**：没有到期日的期货，加密圈最主流的衍生品，**风险极高，新手勿碰**。

### RWA（现实世界资产代币化）`金融`
**Real World Assets**，把房产、债券、应收账款等真实资产变成链上代币，让传统资产可拆分、可全球流通。是 2025-2026 的热门方向，港城大新课程专门覆盖。

### Token / 代币 / NFT `金融`
- **同质化代币（FT）**：比特币、USDC 这类彼此等价、可互换的代币；
- **NFT（非同质化代币）**：独一无二、不可互换，用于数字藏品、门票、产权、身份等。

### DAO（去中心化自治组织）`金融`
用智能合约规则 + 代币投票来共同治理的组织，没有传统层级，决策公开。社区金库、提案、投票都在链上。

### DID（去中心化身份）`金融`
**Decentralized Identity**：不依赖某家公司、由你自己掌控的数字身份 / 凭证，可跨应用使用，是 Monad 黑客松的赛道之一。

### MEV（最大可提取价值）`金融`
矿工 / 验证者 / 交易者通过**操纵交易排序**获利，常见：
- **抢跑（Front-running）**：看到你的买单，抢先买入再卖给你；
- **夹子（Sandwich）**：在你买卖前后夹击赚差价。
Monad 用加密内存池等机制保护用户。

## 三、AI Agent（智能体）

### AI / 机器学习 / 深度学习 `AI`
- **人工智能（AI）**：让机器表现出智能的总称；
- **机器学习（ML）**：让机器从数据中自己找规律；
- **深度学习（DL）**：用多层神经网络的机器学习，是当代 AI 爆发的基础。

### LLM（大语言模型）`AI`
**Large Language Model**：GPT、Claude、DeepSeek、Gemini 这类，通过海量文本训练、擅长理解和生成语言，核心机制是「根据上下文预测下一个词」。

### AI Agent（智能体）`AI`
**能自己规划、调用工具、分多步完成任务的 AI**。普通 ChatGPT 是「你问一句答一句」；Agent 是「你给个目标（如帮我调研市场并写成报告），它自己拆解任务、搜索、读写文件、调用 API、付费，把事办完」。这是本次两场活动的绝对主角。

### 提示词 `Prompt` `AI`
你给 AI 的指令 / 问题。「提示词工程」= 把需求写清楚、写巧妙，让 AI 更好地完成任务。

### API `AI`
**应用程序接口**：软件之间互相调用功能 / 数据的「窗口」。例：天气 App 调用气象 API；Agent 调用付费数据 API。理解 API 是理解 Agent 和 X402 的前提。

### MCP（模型上下文协议）`AI`
**Model Context Protocol**，一种让 AI 标准化连接外部工具 / 数据源 / 服务的「通用插座」。有了它，Agent 即插即用地接数据库、文件、支付等，是 2024-2025 年最重要的 AI 基建之一。

### 幻觉 `Hallucination` `AI`
AI **一本正经地编造看似合理、实则错误的内容**（虚构法条、数据、引用）。涉及事实、合规、金钱时必须核实来源，不能盲信。

### Token（AI 语境）`AI`
模型处理文本的最小单位（词 / 字片段）。模型按 Token 计费、有上下文长度限制。**注意和加密货币的 Token 是两个概念**，语境不同。

### 微调 / RAG `AI`
- **微调（Fine-tuning）**：用专属数据进一步训练模型；
- **RAG（检索增强生成）**：让模型先检索你的资料再回答，是企业知识库的主流做法。

### Vibe Coding `AI`
2025 年流行的说法：**用自然语言指挥 AI 写代码**，人主要负责描述意图和审查结果，大幅降低编程门槛。SignalPlus 团队用它三周做出复杂产品。

### X402 `AI`
基于互联网 HTTP 协议「402 Payment Required（需要付费）」状态码的**支付协议**：程序 / Agent 访问一个收费服务时，按协议自动用稳定币等完成微支付，再拿到服务。是 Agent 自动付费的热门基础协议。

### Agent 支付 / Agent 卡 `AI`
让 Agent 在**人类设定的预算、权限、风控约束内自动花钱**的整套设施；形态包括「Agent Card（映射你信用卡的虚拟卡）」、稳定币钱包等。核心原则：**人给「零花钱」和规则，Agent 不能碰「银行卡」**。

## 四、安全与密码学

### 公钥 / 私钥 / 数字签名 `安全`
- **公钥（公开）+ 私钥（保密）**成对，是现代密码学基础；
- **数字签名**：用私钥对消息盖章，任何人可用公钥验证「确实是你签的、没被改过」，且你无法抵赖。

### 零知识证明 `ZK` `安全`
**Zero-Knowledge Proof**：让你「不透露秘密本身，也能向别人证明某件事为真」。
- 例：证明「我年满 18」但不告诉你生日；证明「我洗牌没作弊」但不亮出牌；
- 常见体系 **zk-STARK、zk-SNARK**。是去中心化扑克、ZK  Rollup、隐私与扩容的核心技术，Web3 最硬核方向之一。

### 审计 `Audit` `安全`
由专业安全公司检查智能合约 / 代码有没有漏洞。DeFi 合约上线前通常需要审计；但审计过 ≠ 绝对安全。

### WASM `安全`
**WebAssembly**：让网页浏览器以接近原生的高速运行程序的技术。果蝇大脑就是在浏览器里用 WASM 跑的。

### AppChain（应用链）`安全`
为某个具体应用专门打造的区块链，以满足极致性能 / 定制需求。成功标杆 **Hyperliquid**（去中心化永续合约交易所，自建专用链）。

### 中间件 `Middleware` `安全`
夹在底层和应用之间、提供通用能力（支付、预算、身份、数据）的软件层。Text Permit、Agent 支付设施都属于中间件。

## 五、行业生态与常用词

### 比特币 `BTC` `生态`
第一个、也是市值最大的加密货币（2009 年诞生），主打「数字黄金 / 价值存储」，脚本功能简单。

### 牛市 / 熊市 `生态`
- **牛市（Bull Market）**：价格普遍上涨、情绪狂热；
- **熊市（Bear Market）**：持续下跌、项目倒闭、冷清。Web3 周期明显，**熊市学习建设、牛市收获**是常见策略。

### VC（风险投资）`生态`
投资早期项目的机构。本次圆桌的 SNC、IOSG 都是加密 VC；黑客松是被 VC 发现的好场合。

### 黑客松 `Hackathon` `生态`
限时（几天到几周）的**创客比赛**：组队快速做出项目 Demo，评委打分发奖金，同时有导师、招聘、融资机会。**大学生入行 Web3 的第一抓手**。

### DevRel（开发者关系）`生态`
**Developer Relations**：在基金会 / 公司负责服务开发者、办活动、做教育布道的岗位（如 Monad 的 Box），是「懂技术 + 会沟通」的复合角色，与语言类学生的方向也有交集。

### 白皮书 `Whitepaper` `生态`
项目阐述技术原理、设计、愿景的官方文档（比特币、以太坊都有著名白皮书）。

### 开源 `Open Source` `生态`
把代码 / 内容公开，允许他人查看、使用、协作改进。Web3 的文化基因，也是个人建立信誉的方式。本 Wiki 即开源项目。

### 幂等性 `Idempotency` `安全`
同一个请求重复发送多次，**结果只生效一次**（如网络重发不会重复扣款）。支付系统的关键设计。

### 路由 `Routing` `AI`
在多个通道 / 路径中，按价格、速度、地区等自动选择最优的一个。Agent 支付的「路由层」被认为是有壁垒的方向。
