# 小白词典

把行业术语翻译成「人话」的地方。

- [**Web3 小白概念词典**](./01-beginner-dictionary.md)：按「区块链基础 → 金融（DeFi）→ AI Agent → 安全与证明 → 行业生态」分类的 40+ 概念；
- [**会议黑话对照表**](./02-jargon-mapping.md)：会议录音转写里的谐音 / 口语词，对应到标准写法。

## 使用方法

1. 读会议精读、看行业文章遇到不懂的词，来这里查；
2. 每学一个概念，尝试**用自己的话给别人讲一遍**（费曼学习法）；
3. 词典会持续扩充，建议你也在自己的笔记里补充例子。

> 提示：这些是「入门级解释」，目的是先建立直觉，严谨定义请结合 [技能与资源](../04-skills/01-skill-tree-resources.md) 里的系统课程。
