# 英语标化与背景提升

> 语言是广外学生的「王牌科目」，目标是把优势变成录取优势；背景提升则是双非逆袭的主战场。

## 一、雅思 / 托福

### 目标分数

| 目标档位 | 建议分数 |
|---|---|
| 主申 / 稳妥（城大、理大、SMU 等） | 雅思 **6.5**（小分 6.0）基本够用 |
| 冲刺港三 / 新二 | 雅思 **7.0+**（小分 6.0-6.5）更稳 |
| 顶尖 / 奖学金 | 雅思 7.5+ 有竞争力 |

> 托福对应参考：雅思 6.5 ≈ 托福 90 左右；雅思 7.0 ≈ 托福 100 左右。港新普遍两者都接受，**选雅思即可**（广外训练体系、口语场景更贴合）。

### 时间规划（关键：成绩 2 年有效）

- **大一**：打基础 + 模考 / 一战摸底（不急于出分，先暴露问题）；
- **大二上学期**：**正式出分 7.0**，留出二战空间；
- 若大三申请时成绩将过期，安排在**大三下 ~ 暑假**重考（注意让成绩在申请和入学时都有效）。

### 备考策略（结合专业）

- **听力 / 阅读**：直接用英文 Web3 / AI 资料当素材，备考和专业学习一举两得；
- **写作**：把 Wiki 笔记的英文摘要、X 发帖当练习；
- **口语**：用英语复述项目、参加线上英语角 / 国际社群语音；
- 广外的外教、语言课、英语角是免费资源，多用。

## 二、GRE / GMAT

### 要不要考

- **明确建议 / 要求的项目**：NUS DFinTech（参考 **GRE 320+ / GMAT 700+**）、HKUST FinTech（强烈建议）；
- 其他港校多数不强制，但**高分能加分、对冲双非背景**。

### 选哪个

- **GRE**：适用面更广，理工、金融科技、数据 / 计算机方向都认可，**优先选 GRE**；
- **GMAT**：纯商学院 / 金融方向更对口（如 HKU MFFinTech）；
- 时间：**大三上 ~ 暑假**集中攻克，别和申请季撞车。

> 标化是「门票」不是「亮点」，达到目标线即可，不必无限刷分；时间更应留给 GPA、项目和实习。

## 三、背景提升（双非逆袭核心）

### 1. 交换 / 暑校 / 联合培养

- 优先争取**港、新的学期交换 / 暑期学校**（提前接触目标院校、拿推荐信、体验当地）；
- 关注学校国际处的合作项目、资助名额；
- 线上的国际课程 / 证书（Coursera、edX 名校课）也可作为补充，但**线下 / 有成绩单和推荐信的项目含金量更高**。

### 2. 科研（学术向，冲研究型 / 名校很重要）

- 大二起主动联系教授做 **RA（研究助理）**，方向贴合区块链 / AI 金融 / 数据；
- 争取产出：会议 / 工作坊论文、技术报告、公开数据集；
- 即使是授课型硕士，**科研经历也能显著提升故事的可信度**，并拿到学术推荐信。

### 3. 竞赛

| 类型 | 例子 | 价值 |
|---|---|---|
| **黑客松**（最重要） | Monad、ETH Global、Dorahacks | 直接对口，有奖金 + 作品 + 人脉 |
| 数据 / AI | Kaggle、天池、数据竞赛 | 证明工程与数据能力 |
| 数学建模 | 国赛 / 美赛（MCM/ICM） | 量化能力背书 |
| 商赛 | 金融 / 咨询 / 创业大赛 | 适合复合 / 非技术路线 |

### 4. 实习（权重最高的软背景之一）

- 目标：**2-3 段 Web3 / 金融科技相关实习**，优先知名项目、港新实地、有推荐信；
- 大一可从远程 / 运营 / 内容 / 社区切入，逐步过渡到技术 / 投研；
- 详见 [Web3 实习求职指南](../05-playbooks/03-internship-job-guide.md)。

### 5. 作品集 / 个人 IP

- 这个 **GitHub Wiki + 项目仓库 + 个人网站**就是四年的核心作品集；
- 公开的技术博客、开源贡献、X 内容，构成可验证的「能力证据链」；
- 详见 [GitHub 与个人 IP 搭建指南](../05-playbooks/02-github-and-personal-ip.md)。

### 6. 推荐信策略

- 理想组合：**1 位专业课 / 科研教授 + 1 位实习 / 项目负责人 + 1 位交换 / 业界导师**；
- 推荐信要「具体」：推荐人能讲出你做过的项目、表现出的能力；
- 从大一就要让老师记住你（上课、提问、做项目、帮老师干活），**临时抱佛脚要不到强推**。

## 四、背景提升时间总表

| 学年 | 语言 / 标化 | 科研 / 交换 | 竞赛 / 实践 |
|---|---|---|---|
| 大一 | 雅思基础 + 一战摸底 | 认识老师、进实验室旁听 | 逛黑客松、建 Wiki |
| 大二 | **雅思出分 7.0** | RA / 港新暑校 | **第一次黑客松**、1 段实习 |
| 大三 | **GRE/GMAT**、必要时重考雅思 | 论文 / 研究产出 | 黑客松获奖、**2 段强实习** |
| 大四 | 补齐有效期 | 毕设结合 Web3 | 申请、面试、拿 Offer |

## 五、文书故事线（提前四年经营）

招生官想看到一个**连贯、可信、有证据**的故事，例如：

> 「我在大一下接触到 AI Agent 支付这一真实趋势（附会议精读笔记）→ 被『让 AI 安全地参与经济』吸引而系统学习智能合约（附课程与项目）→ 通过黑客松和实习不断验证兴趣与能力（附作品、获奖、推荐信）→ 现在希望在贵校（具体到课程 / 教授 / 生态）深入，未来投身港 / 新的数字资产行业。」

**这个故事不是大四「写」出来的，是四年「做」出来的。** 每篇笔记、每个项目，都是在为文书攒素材。
