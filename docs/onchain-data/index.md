# 链上数据 · On-chain Data

## 主题

- **数据源**：RPC 节点、Indexer、Dune / Nansen 等分析平台；
- **数据质量**：去重、标准化、时间戳与地址格式，链上数据的「脏数据」问题；
- **查询实践**：Dune SQL 查询、仪表盘构建与常用模式；
- **应用**：链上指标、市场复盘与 AI × 数据的结合。
