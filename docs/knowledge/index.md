# 知识库

<p class="w3-lead">
这里把笔记里反复遇到的概念按主题放在一起。刚入门可以从基础往下读；带着问题来的，直接找对应的一节就好。

## Basics · 先补基础

- [区块链基础](../fundamentals/index.md)：先认识钱包、交易、Gas、共识和 L1 / L2。遇到不熟悉的词，可以随时翻[核心概念词典](../fundamentals/core-concepts.md)。
- [链上数据](../onchain-data/index.md)：数据从哪里来、怎么查、哪些地方容易误读。也收了 Dune 等分析平台的入口。

## Build · 开始写点东西

- [智能合约](../smart-contracts/index.md)：从 Solidity 和 Foundry 入手，在测试网上走一遍写合约、测试和部署的流程。
- [开发者工具](../devtools/index.md)：Git / GitHub、合约开发框架和测试网工具。搭环境或找工具时回来查。
- [AI 辅助开发](../devtools/ai-coding.md)：理解 LLM、Agent 和 Harness，整理上下文，用 `AGENTS.md` 和 Skills 约定工作方式。也记了 AI 写完代码之后该怎么审核。

## Explore · 沿着问题往深处走

- [AI × Web3](../ai-web3/index.md)：Agent 支付、链上 Agent、AI 交易和数据资产。从具体案例看这两个方向怎么接上。
- [MCP 与 AI Agents](../ai-web3/mcp-agents.md)：Agent 怎么调用工具、怎么付钱，以及预算和权限怎么管。
- [安全与隐私](../security/index.md)：从钱包和资产安全开始，再看密码学、链上隐私与 Agent 的权限边界。第一次接触钱包时就可以先看这一页。

## 按问题查

- **笔记里有个词看不懂？** 翻[核心概念词典](../fundamentals/core-concepts.md)。
- **想知道怎么保管好自己的币？** 从[资产安全](../security/index.md#assets)开始。
- **想用 AI 写代码，但总是出错？** 看[AI 辅助开发](../devtools/ai-coding.md)里的上下文管理和审核方法。
- **想理解 Agent 怎么付钱、怎么被管住？** 看[MCP 与 AI Agents](../ai-web3/mcp-agents.md)。
- **想写第一个合约？** 先读[智能合约](../smart-contracts/index.md)，需要完整课程时再去[精选课程中心](../roadmap/courses.md)。

## 怎么用

第一遍先知道每一块在讲什么，读活动笔记或做项目时再回来查。试着用自己的话解释一个概念，讲不清的地方往往就是下一步该补的内容。

发现解释不准确或过时，欢迎在群里说，或者点右上角 **Edit on GitHub** 直接改。参与方式见[贡献指南](../contributing.md)。
