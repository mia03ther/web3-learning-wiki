# 四年路线图

把「广外大一 → 港 / 新 Web3 硕士 → 入行」拆成四年可执行的计划。

- [**四年总路线图**](./01-four-year-roadmap.md)：每年的学业、英语、技术、实践、输出目标，以及申请季时间轴；
- [**港新 Web3 硕士项目清单**](./02-hk-sg-masters.md)：香港、新加坡相关硕士的方向、要求、学费与申请策略，含「双非」逆袭逻辑。

## 先看三句话

1. **GPA 是双非逆袭的第一硬通货**，从大一第一节课就要拉满，没有「以后再补」；
2. **雅思尽早出分**（广外优势），大一启蒙、大二出分，后面才能安心做项目和实习；
3. **软背景靠四年攒**：黑客松、GitHub 项目、Web3 实习、科研、推荐信，一样都不能少，但要按节奏来，不焦虑。

> 信息核查于 2026 年 9 月。你实际申请的是 **2030 年秋季入学**（2029 年秋递交），项目要求届时会更新，本文档定位是「方向锚点」，每年都要回来对照官网修订。
