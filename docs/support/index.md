<div class="w3-support" markdown="1">

<div class="w3-support-intro">

**A Web3 Learning Wiki** 是一个完全免费、开源的个人学习档案。

没有广告、没有付费墙、没有订阅。每一页内容都来自我自己搭建项目、参加黑客松和
阅读官方文档的真实过程，全部以 [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/) 开源。

如果你在这里找到了真正有用的内容，欢迎请我喝杯咖啡 —— 这笔支持会被用在
服务器、域名和 API 费用上，让我有更多时间继续更新。
