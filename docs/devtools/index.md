# 开发者工具 · Developer Tools

- **版本控制**：Git / GitHub 基础与团队协作流程；
- **链上开发**：Remix、Foundry、Hardhat 与测试网工作流；
- **本地站点**：MkDocs 搭建与维护（本站就是实例）；
- **效率工具**：终端、AI 辅助编码、文档与知识管理。
