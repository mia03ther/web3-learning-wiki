# 开发者工具 · Developer Tools

Builder 日常使用的工具链与工作流：从 Git 到部署，从终端到链上开发环境。

## 主题

- **版本控制**：Git / GitHub 基础与团队协作流程；
- **链上开发**：Remix、Foundry、Hardhat 与测试网工作流；
- **本地站点**：MkDocs 搭建与维护（本站就是实例）；
- **效率工具**：终端、AI 辅助编码、文档与知识管理。

## 最近怎么用上这些工具

- [Bittensor 的环境排错](../field-notes/bittensor-study-camp.md#environment)：钱包与命令行、WSL、Docker 客户端和引擎分别负责什么，成功输出能证明哪一步。
- [Reactive 的 Foundry 练习](../field-notes/reactive-network.md#my-progress)：本地测试、用 `cast` 读取参数，以及部署前该保存什么证据。
